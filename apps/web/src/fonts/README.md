# Fonts

Self-hosted so the site makes no third-party requests and fits the `font-src 'self'` CSP.
Both fonts are licensed under the SIL Open Font License 1.1 (see the `OFL-*.txt` files).

| File | Font | Source |
|---|---|---|
| `bricolage-grotesque-latin-wght-normal.woff2` | Bricolage Grotesque (variable weight), headings | `@fontsource-variable/bricolage-grotesque@5.3.0` |
| `plus-jakarta-sans-latin-wght-normal.woff2` | Plus Jakarta Sans (variable weight), body text | `@fontsource-variable/plus-jakarta-sans@5.3.0` |

The npm tarballs were checked against the registry's published sha512 integrity before copying.
